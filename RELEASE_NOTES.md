# Tiny Planner 1.0.3

This release gives the verified 1.0.2 corrections a distinct version for a new Obsidian Community release review. Runtime code, interface and data format match the corrected 1.0.2 build.

- Retain the guarded Obsidian 1.13 settings API and legacy settings support for Obsidian 1.7.2–1.12.
- Retain transparent completion circles and sidebar utility buttons, aligned navigation and responsive Day/Week/Month layouts.
- Keep strict verification that the committed `main.js` matches the TypeScript sources. Release publication supports retries and uses these notes as its description.
- Correct the installation and publication instructions to remove the obsolete automatic bundle synchronization procedure.

Update the separate `main.js`, `manifest.json` and `styles.css` files together. Obsidian 1.7.2 or newer is required. Existing planner notes and settings remain in your vault.

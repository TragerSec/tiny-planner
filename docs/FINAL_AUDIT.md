Исправление опубликованной 1.0.4. Старый тег не переписывается; отправка в GitHub и публикация здесь не выполнялись. Минимальная версия Obsidian 1.7.2 и схема 1 сохранены.

## Отчёт Obsidian

| Замечание | Результат |
| --- | --- |
| no-static-styles-assignment в модальном окне | Высота textarea меняется через setCssStyles; статического присваивания style.height больше нет |
| prefer-create-el в полях выбора | Используются createDiv/createSpan в документе родительского элемента |

| multicolumn в CSS | В отчёте были column-gap на Grid/Flex. Заменены эквивалентными gap с сохранением расстояний по обеим осям; multi-column layout не используется |
| Три :has | Удалены. Класс tp-card-expanded синхронно отражает раскрытие карточки при клике, клавиатуре и закрытии снаружи. Событие toggle поддерживает программные изменения без рекурсивных вызовов |
| Три !important | Сохранены осознанно только для прозрачного фона, отсутствия рамки и тени на конкретных кнопках. Обычная специфичность не перекрывает important-заливку темы. Регрессионный тест враждебной темы сохранён |

## Постоянная защита в CI

Добавлен `npm run lint:obsidian`: полный recommended-набор официального eslint-plugin-obsidianmd для собственных TypeScript-исходников, без отключения правил и с нулевым допустимым количеством предупреждений. Название Tiny Planner зарегистрировано как бренд в проверке sentence case. Тестовые макеты и сторонние декларации не смешиваются с собственным runtime; для деклараций отдельно действует no-explicit-any.

Проверка включена в `npm run check` и тем самым в оба GitHub workflow. Изолированный tools/obsidian-lint имеет точные версии и lockfile, устанавливается через npm ci --ignore-scripts, отдельно аудируется и проверяет подписи. Код этих инструментов не входит в main.js. В toolchain закреплён moment 2.31.0 для устранения advisory из транзитивных зависимостей линтера.

Три правки сторонних деклараций описаны в vendor/rrule/README.md. Тест происхождения обращает ровно эти правки перед побайтовым сравнением с npm. Исполняемые файлы rrule не изменены, кроме ранее задокументированной защиты итератора. Нет blanket-исключения для произвольных изменений vendor.

## Регрессии и безопасность

При замене :has браузерная проверка обнаружила задержку обновления CSS-класса раскрытия. Исправлено синхронным изменением details.open и класса в одном действии. Тест видимости полного названия не ослаблен.

Typed lint дополнительно выявил преобразования произвольных YAML-коллекций в строки. Они заменены проверкой scalarText: дата, текст, числа и логические значения обрабатываются явно. Коллекции не вызывают пользовательское преобразование в строку; некорректное повторение остаётся отмеченным как неподдерживаемое. Новая регрессия проверяет это поведение.

Зависимости приложения и инструментария не содержат известных advisories по npm audit. Проверены подписи 61 пакета приложения и 332 пакетов инструментария, а также 4 и 60 attestations соответственно. В собственном runtime нет сетевого клиента, shell/eval или вставки HTML из заметок; содержимое заметок выводится как текст.

## Границы проверки

Локальная проверка официальным линтером не является результатом удалённого автоматического review Obsidian. После публикации 1.0.5 его нужно запустить заново. Допустимые рекомендации о полном сканировании Markdown и трёх узких important-правилах могут остаться в отчёте; они явно раскрыты выше.

Браузерные проверки используют макет Obsidian API; настоящие Android/iOS и минимальная версия приложения требуют ручной проверки по OBSIDIAN-QA.md. Календарь из 5000 карточек остаётся тяжёлым: все карточки сохраняются согласно требованиям, без вложенной прокрутки.
